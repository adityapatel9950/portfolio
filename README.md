## ✨ About the Project

This is my personal developer portfolio built from scratch using **HTML5, CSS3, and  JavaScript**.

The portfolio is designed to showcase my technical skills, projects, achievements, and developer journey through a modern, interactive, and responsive interface.

---

## ⚡ Features

- 🎨 Modern dark-themed UI
- 🪟 Glassmorphism design
- ✨ Smooth animations and transitions
- 🖱️ Interactive cursor glow
- 🌌 Animated particle background
- ⌨️ Typewriter effect
- 📱 Fully responsive design
- 🧭 Mobile-friendly navigation
- 💻 Projects showcase
- 🛠️ Skills & technologies section
- 👨‍💻 About Me section
- 📬 Interactive contact section
- ⚡ Lightweight and fast
- 🌐 GitHub Pages deployment
